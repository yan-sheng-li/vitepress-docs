## PowerShell 禁止运行脚本

> Windows 系统默认的安全策略，旨在防止意外执行恶意脚本。

**1. 以管理员身份打开 PowerShell**

- 点击“开始”菜单，输入 `PowerShell`。
- 在搜索结果中，右键点击 “Windows PowerShell”，选择 **“以管理员身份运行”**。

**2. 修改执行策略**

- 在弹出的管理员窗口中，输入以下命令并回车：

```powershell
Set-ExecutionPolicy RemoteSigned
```

解决：切换matplotlib后端

```python

```

或者在你的`main.py`文件最顶部添加：

```python
import matplotlib.pyplot as plt
plt.switch_backend('TkAgg')
```

**查看系统版本**

```bash
getprop ro.build.version.sdk
```

```bash
echo 'export ANDROID_API_LEVEL=33' >> ~/.bashrc
source ~/.bashrc
```

## MySQL服务器认证方式不兼容

表现：

```bash
2059 - Authentication plugin 'caching_sha2_password' cannot be loaded: ◆X◆◆◆◆◆◆◆g�d
```

解决：

> 修改用户认证插件

**登录MySQL**

**执行修改命令**：

```sql
-- 将 '你的用户名' 和 '你的密码' 以及 '你的主机名' 替换成实际值
-- 'localhost' 代表只允许本地连接，如果你的应用在其他机器，可能需要改成 '%' 或具体IP
ALTER USER '你的用户名'@'localhost' IDENTIFIED WITH mysql_native_password BY '你的密码';

-- 刷新权限使修改生效
FLUSH PRIVILEGES;
```

**重新尝试连接**：用新密码重新连接即可

此外，跳过权限验证启动

**Windows 操作：**

```bash
# 进入MySQL的bin目录（比如 C:\Program Files\MySQL\MySQL Server 8.0\bin）
cd /d "C:\Program Files\MySQL\MySQL Server 8.0\bin"

# 以跳过权限表模式启动（注意：这个窗口要一直开着，不能关）
mysqld --skip-grant-tables --shared-memory
```

**新开一个**命令行窗口（管理员模式），然后：

```bash
# 直接回车，不输密码
mysql -u root
```

正常情况下，你应该能直接进入 `mysql>` 命令行界面了。
